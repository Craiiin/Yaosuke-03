# 贝塞尔曲线绘制实验（De Casteljau 算法 + Taichi GPU 加速）
基于 **Taichi** 编程语言实现的交互式贝塞尔曲线绘制系统，采用 **De Casteljau 算法** 计算曲线坐标，结合 GPU 并行加速实现高帧率、无卡顿的实时绘制效果，支持鼠标交互添加控制点与键盘清空操作。

## 功能特性
- ✅ **De Casteljau 算法**：精确计算任意阶数贝塞尔曲线坐标
- ✅ **GPU 并行加速**：像素绘制与数据处理在 GPU 端并行执行，解决高采样率卡顿问题
- ✅ **交互式操作**：鼠标左键添加控制点，`C` 键一键清空画布
- ✅ **可视化辅助**：红色圆点标记控制点，灰色连线显示控制多边形
- ✅ **高流畅度**：1000 段曲线采样，稳定高帧率运行
- ✅ **显存优化**：采用数据缓冲池 + 批量数据传输，大幅降低 CPU-GPU 通信开销

## 环境依赖
```text
taichi >= 1.6.0
numpy >= 1.21.0
```

## 安装命令
```bash
pip install taichi numpy
```

## 操作说明
| 操作 | 功能 |
|------|------|
| 鼠标左键点击 | 添加曲线控制点（最多支持 100 个） |
| 键盘按下 `C` | 清空所有控制点与曲线 |
| 程序运行 | 自动绘制贝塞尔曲线 + 控制点 + 辅助线 |

## 核心实现原理
### 1. De Casteljau 算法
纯 Python 实现递归式 De Casteljau 算法，输入控制点集合与参数 `t∈[0,1]`，输出曲线上对应坐标，保证曲线计算精度。

### 2. GPU 加速架构
- **像素缓冲区**：800×800 矢量场存储屏幕像素颜色
- **曲线数据缓冲区**：预分配 GPU 内存，批量存储 1001 个曲线采样点
- **并行绘制内核**：`draw_curve_kernel` 在 GPU 上并行点亮像素，性能提升显著
- **对象池优化**：固定长度缓冲区存储动态控制点，超出部分置于屏幕外不可见

### 3. 渲染流程
1. CPU 计算所有曲线采样点坐标
2. 批量传输数据至 GPU 显存
3. GPU 并行绘制曲线像素
4. 叠加绘制控制点与辅助线
5. 实时刷新画面输出

## 代码结构
```
├── 初始化配置        GPU 模式、窗口尺寸、缓冲区定义
├── de_casteljau()    De Casteljau 算法实现
├── clear_pixels()    GPU 并行清空画布
├── draw_curve_kernel()  GPU 并行绘制曲线
└── main()            主循环、事件监听、渲染逻辑
```

## 实验参数
- 窗口分辨率：`800 × 800`
- 最大控制点数量：`100`
- 曲线采样段数：`1000`
- 控制点半径：`0.006`
- 辅助线宽度：`0.002`
- 曲线颜色：绿色；控制点颜色：红色；辅助线颜色：灰色

## 项目亮点
1. **性能优化**：解决传统 CPU 绘制高采样曲线卡顿问题，GPU 并行处理提升运行效率
2. **交互友好**：极简操作逻辑，适合计算机图形学教学与实验演示
3. **架构清晰**：模块化设计，便于学习贝塞尔曲线原理与 GPU 编程思想
